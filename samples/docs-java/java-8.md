Release facts for Java 8, a LTS release of the Java platform.

## Release facts
Java 8 reached general availability on 2014-03-18 as a long-term support (LTS) release.
Its support window is scheduled to end in 2027-07.
The release is defined by umbrella JSR 337.

## Class files and Unicode
The compiler in Java 8 emits class files with major version 52.0.
Java 8 bundles Unicode version 6.2.0.

## Maintenance updates
Java 8 has received 33 maintenance updates in this snapshot; the most recent is 8u504, released 2026-08-19.
The reference implementation sources are maintained at https://github.com/openjdk/jdk8u.
