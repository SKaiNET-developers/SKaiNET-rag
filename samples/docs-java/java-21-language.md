Java 21 shipped 5 language changes. Each section covers one of them.

## String Templates
String Templates is a language change in Java 21, specified by JEP 430.
Java 21 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Record Patterns
Record Patterns is a language change in Java 21, specified by JEP 440.
It shipped as a final, fully supported change in Java 21.

## Pattern Matching for switch
Pattern Matching for switch is a language change in Java 21, specified by JEP 441.
It shipped as a final, fully supported change in Java 21.

## Unnamed Patterns and Variables
Unnamed Patterns and Variables is a language change in Java 21, specified by JEP 443.
Java 21 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Unnamed Classes and Instance Main Methods
Unnamed Classes and Instance Main Methods is a language change in Java 21, specified by JEP 445.
Java 21 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.
