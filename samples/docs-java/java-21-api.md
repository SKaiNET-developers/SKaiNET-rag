Java 21 shipped 7 API changes. Each section covers one of them.

## Sequenced Collections
Sequenced Collections is an API change in Java 21, specified by JEP 431.
It shipped as a final, fully supported change in Java 21.

## Foreign Function & Memory API
Foreign Function & Memory API is an API change in Java 21, specified by JEP 442.
Java 21 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Virtual Threads
Virtual Threads is an API change in Java 21, specified by JEP 444.
It shipped as a final, fully supported change in Java 21.

## Scoped Values
Scoped Values is an API change in Java 21, specified by JEP 446.
Java 21 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Vector API
Vector API is an API change in Java 21, specified by JEP 448.
Java 21 ships it as an incubating module: the API lives in the jdk.incubator namespace and is not yet part of the Java SE standard.

## Key Encapsulation Mechanism API
Key Encapsulation Mechanism API is an API change in Java 21, specified by JEP 452.
It shipped as a final, fully supported change in Java 21.

## Structured Concurrency
Structured Concurrency is an API change in Java 21, specified by JEP 453.
