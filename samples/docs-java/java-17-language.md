Java 17 shipped 3 language changes. Each section covers one of them.

## Restore Always-Strict Floating-Point Semantics
Restore Always-Strict Floating-Point Semantics is a language change in Java 17, specified by JEP 306.
It shipped as a final, fully supported change in Java 17.

## Pattern Matching for switch
Pattern Matching for switch is a language change in Java 17, specified by JEP 406.
Java 17 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Sealed Classes
Sealed Classes is a language change in Java 17, specified by JEP 409.
It shipped as a final, fully supported change in Java 17.
