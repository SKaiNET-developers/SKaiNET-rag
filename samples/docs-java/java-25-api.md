Java 25 shipped 6 API changes. Each section covers one of them.

## PEM Encodings of Cryptographic Objects
PEM Encodings of Cryptographic Objects is an API change in Java 25, specified by JEP 470.
Java 25 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Stable Values
Stable Values is an API change in Java 25, specified by JEP 502.
Java 25 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Structured Concurrency
Structured Concurrency is an API change in Java 25, specified by JEP 505.
Java 25 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Scoped Values
Scoped Values is an API change in Java 25, specified by JEP 506.
It shipped as a final, fully supported change in Java 25.

## Vector API
Vector API is an API change in Java 25, specified by JEP 508.
Java 25 ships it as an incubating module: the API lives in the jdk.incubator namespace and is not yet part of the Java SE standard.

## Key Derivation Function API
Key Derivation Function API is an API change in Java 25, specified by JEP 510.
It shipped as a final, fully supported change in Java 25.
