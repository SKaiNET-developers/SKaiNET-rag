This corpus covers the long-term support (LTS) releases of Java: Java 8, Java 11, Java 17, Java 21, Java 25.

## Release timeline
Java 8 reached general availability on 2014-03-18.
Java 11 reached general availability on 2018-09-25.
Java 17 reached general availability on 2021-09-14.
Java 21 reached general availability on 2023-09-19.
Java 25 reached general availability on 2025-09-16.

## Class-file versions
Class files compiled for Java 8 carry major version 52.0.
Class files compiled for Java 11 carry major version 55.0.
Class files compiled for Java 17 carry major version 61.0.
Class files compiled for Java 21 carry major version 65.0.
Class files compiled for Java 25 carry major version 69.0.
To find out which Java release a class file needs, read its major version: 52 means Java 8, 55 means Java 11, 61 means Java 17, 65 means Java 21, 69 means Java 25.

## Support windows
Support for Java 8 is scheduled to end in 2027-07.
Support for Java 11 is scheduled to end in 2027-10.
Support for Java 17 is scheduled to end in 2027-10.
Support for Java 21 is scheduled to end in 2029-12.
Support for Java 25 is scheduled to end in 2030-09.
