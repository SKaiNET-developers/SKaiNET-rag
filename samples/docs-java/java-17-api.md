Java 17 shipped 6 API changes. Each section covers one of them.

## Enhanced Pseudo-Random Number Generators
Enhanced Pseudo-Random Number Generators is an API change in Java 17, specified by JEP 356.
It shipped as a final, fully supported change in Java 17.

## Deprecate the Applet API for Removal
Deprecate the Applet API for Removal is an API change in Java 17, specified by JEP 398.
It shipped as a final, fully supported change in Java 17.

## Remove RMI Activation
Remove RMI Activation is an API change in Java 17, specified by JEP 407.
It shipped as a final, fully supported change in Java 17.

## Deprecate the Security Manager for Removal
Deprecate the Security Manager for Removal is an API change in Java 17, specified by JEP 411.
It shipped as a final, fully supported change in Java 17.

## Foreign Function & Memory API
Foreign Function & Memory API is an API change in Java 17, specified by JEP 412.
Java 17 ships it as an incubating module: the API lives in the jdk.incubator namespace and is not yet part of the Java SE standard.

## Vector API
Vector API is an API change in Java 17, specified by JEP 414.
Java 17 ships it as an incubating module: the API lives in the jdk.incubator namespace and is not yet part of the Java SE standard.
