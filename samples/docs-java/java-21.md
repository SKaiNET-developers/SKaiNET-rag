Release facts for Java 21, a LTS release of the Java platform.

## Release facts
Java 21 reached general availability on 2023-09-19 as a long-term support (LTS) release.
Its support window is scheduled to end in 2029-12.
The release is defined by umbrella JSR 396.

## Class files and Unicode
The compiler in Java 21 emits class files with major version 65.0.
Java 21 bundles Unicode version 15.0.0.

## Maintenance updates
Java 21 has received 13 maintenance updates in this snapshot; the most recent is 21.0.12.1, released 2026-08-07.
The reference implementation sources are maintained at https://github.com/openjdk/jdk21u.
