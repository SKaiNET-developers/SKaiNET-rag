Release facts for Java 25, a LTS release of the Java platform.

## Release facts
Java 25 reached general availability on 2025-09-16 as a long-term support (LTS) release.
Its support window is scheduled to end in 2030-09.
The release is defined by umbrella JSR 400.

## Class files and Unicode
The compiler in Java 25 emits class files with major version 69.0.
Java 25 bundles Unicode version 16.0.0.

## Maintenance updates
Java 25 has received 5 maintenance updates in this snapshot; the most recent is 25.0.4.1, released 2026-08-07.
The reference implementation sources are maintained at https://github.com/openjdk/jdk25u.
