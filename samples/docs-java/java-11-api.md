Java 11 shipped 6 API changes. Each section covers one of them.

## HTTP Client
HTTP Client is an API change in Java 11, specified by JEP 321.
It shipped as a final, fully supported change in Java 11.

## Java EE and CORBA removed
Java EE and CORBA removed is an API change in Java 11, specified by JEP 320.
It shipped as a final, fully supported change in Java 11.

## Unicode 10 Support
Unicode 10 Support is an API change in Java 11, specified by JEP 327.
It shipped as a final, fully supported change in Java 11.

## Nashorn JavaScript Engine deprecated
Nashorn JavaScript Engine deprecated is an API change in Java 11, specified by JEP 335.
It shipped as a final, fully supported change in Java 11.

## New Cryptographic Algorithms
New Cryptographic Algorithms is an API change in Java 11, specified by JEP 324 and JEP 329.
It shipped as a final, fully supported change in Java 11.

## TLS 1.3
TLS 1.3 is an API change in Java 11, specified by JEP 332.
