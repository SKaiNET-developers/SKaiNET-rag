Release facts for Java 17, a LTS release of the Java platform.

## Release facts
Java 17 reached general availability on 2021-09-14 as a long-term support (LTS) release.
Its support window is scheduled to end in 2027-10.
The release is defined by umbrella JSR 392.

## Class files and Unicode
The compiler in Java 17 emits class files with major version 61.0.
Java 17 bundles Unicode version 13.0.0.

## Maintenance updates
Java 17 has received 23 maintenance updates in this snapshot; the most recent is 17.0.20.1, released 2026-08-07.
The reference implementation sources are maintained at https://github.com/openjdk/jdk17u.
