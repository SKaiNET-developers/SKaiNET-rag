Java 25 shipped 4 language changes. Each section covers one of them.

## Primitive Types in Patterns, instanceof, and switch
Primitive Types in Patterns, instanceof, and switch is a language change in Java 25, specified by JEP 507.
Java 25 ships it as a preview feature: it must be enabled with --enable-preview and can still change before it becomes final.

## Module Import Declarations
Module Import Declarations is a language change in Java 25, specified by JEP 511.
It shipped as a final, fully supported change in Java 25.

## Compact Source Files and Instance Main Methods
Compact Source Files and Instance Main Methods is a language change in Java 25, specified by JEP 512.
It shipped as a final, fully supported change in Java 25.

## Flexible Constructor Bodies
Flexible Constructor Bodies is a language change in Java 25, specified by JEP 513.
It shipped as a final, fully supported change in Java 25.
