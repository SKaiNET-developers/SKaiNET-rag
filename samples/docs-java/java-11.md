Release facts for Java 11, a LTS release of the Java platform.

## Release facts
Java 11 reached general availability on 2018-09-25 as a long-term support (LTS) release.
Its support window is scheduled to end in 2027-10.
The release is defined by umbrella JSR 384.

## Class files and Unicode
The compiler in Java 11 emits class files with major version 55.0.
Java 11 bundles Unicode version 10.0.0.

## Maintenance updates
Java 11 has received 37 maintenance updates in this snapshot; the most recent is 11.0.32.1, released 2026-08-19.
The reference implementation sources are maintained at https://github.com/openjdk/jdk11u.
